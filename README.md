# Política de privacidad de ORMISCO

**Última actualización: 12 de septiembre de 2026**

ORMISCO es una aplicación desarrollada por **Lagartobi Studio** para organizar objetos y sus ubicaciones.

## Datos almacenados por ORMISCO

ORMISCO permite al usuario almacenar información sobre sus objetos y ubicaciones, incluyendo nombres, cantidades, notas y fotografías.

Esta información se almacena localmente en el dispositivo del usuario. ORMISCO no dispone de servidores propios a los que se envíe esta información y no requiere la creación de una cuenta de usuario.

## Fotografías y cámara

ORMISCO puede utilizar la cámara del dispositivo para añadir fotografías y para escanear códigos QR relacionados con las ubicaciones del inventario.

Las fotografías y la información obtenida mediante los códigos QR se procesan para proporcionar estas funciones y no son enviadas por ORMISCO a servidores del desarrollador.

## Copias de seguridad

El usuario puede crear voluntariamente copias de seguridad que contienen sus ubicaciones, objetos, notas y fotografías.

La copia se genera localmente y el usuario decide dónde guardarla mediante el sistema de selección de archivos de Android. ORMISCO no envía automáticamente estas copias al desarrollador.

## Compras dentro de la aplicación

ORMISCO puede ofrecer funciones adicionales mediante una compra de la versión PRO.

Las compras son procesadas por Google Play. Lagartobi Studio no recibe ni almacena los datos bancarios o de tarjetas utilizados para realizar el pago.

## Publicidad y analítica

ORMISCO no contiene publicidad y no utiliza servicios propios de seguimiento o analítica para recopilar información sobre el usuario.

## Compartición de datos

Lagartobi Studio no vende los datos del usuario ni comparte el contenido de su inventario con terceros.

## Cambios en esta política

Esta política podrá actualizarse si futuras versiones de ORMISCO incorporan funciones que modifiquen el tratamiento de datos. La fecha de la última actualización aparecerá al comienzo de esta política.
